Below is a selection of my key projects and selected publications from my research career. {% for post in site.portfolio %} {% include archive-single.html type="grid" %} {% endfor %} --- ## Key Projects & Selected Publications **AI-Bind: Interpretable ML for Protein-Ligand Binding** AI-Bind is a deep-learning pipeline designed to improve predictions for how novel protein targets and ligands bind to each other. It overcomes the limitations of traditional models by combining network-based sampling strategies with unsupervised pre-training, leading to more accurate binding predictions. It also offers an interpretable approach to predictions by identifying potential active binding sites on the amino acid sequence, significantly accelerating drug discovery. **Inductive Link Prediction for Isolated Nodes (ILP)** This research tackles the challenge of predicting links for newly introduced or isolated nodes in both static and temporal graphs. Many state-of-the-art models struggle with low-degree nodes due to observation bias and reliance on topological neighborhoods. ILP proposes a training approach using unsupervised pre-training on large corpora to generate informative attributes, enhancing the overall generalizability and accuracy of inductive link predictions. **Transfer Learning for Temporal Link Prediction (fm4tlp)** This project explores transfer learning methodologies to improve link prediction in dynamic and evolving networks. By leveraging models pre-trained on diverse network structures, it enhances the prediction of temporal connections even when longitudinal data is sparse, providing stronger predictive performance over traditional baseline approaches. **MultiViz: Gephi Plugin for Multilayer Networks** MultiViz is a specialized plugin for Gephi that enables the scalable visualization and analysis of multilayer networks. Multilayer networks capture complex systems where nodes can interact across multiple dimensions or contexts. This tool assists researchers in visualizing these interconnected systems and easily deriving insights from graph-based data structures without writing custom rendering code.
