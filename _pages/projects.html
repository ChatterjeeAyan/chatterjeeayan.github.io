The company works at the intersection of network science, large language models, and computational biology to accelerate the path from bench to clinic for rare and genetic diseases. --- ## Research Projects ### AI-Bind — Interpretable ML for Protein-Ligand Binding Predicting how drug-like molecules bind to protein targets is a fundamental challenge in early-stage drug discovery. AI-Bind is a deep-learning pipeline that improves binding predictions for novel protein targets and ligands by combining **network-based negative sampling** with **unsupervised molecular pre-training**. Unlike existing models that exploit topological shortcuts, AI-Bind maximizes inductive generalization and provides interpretable predictions by identifying potential active binding sites on amino acid sequences — significantly accelerating the computational drug discovery pipeline. Published in *Nature Communications* (2023), 219 citations. ### Topology-Driven Negative Sampling for Protein-Protein Interaction Prediction Protein-protein interaction (PPI) prediction underpins therapeutic development, yet graph neural network models often learn structural shortcuts rather than biologically meaningful patterns. This work systematically decouples node attributes from graph topology, revealing that standard negative sampling creates observational biases that impair generalizability. We propose a **topology-driven negative sampling strategy** that forces models to learn interaction patterns based on biological features rather than structural artifacts, achieving state-of-the-art generalizability on held-out PPI datasets. Published in *Bioinformatics*, Oxford (2025). ### Transfer Learning for Temporal Link Prediction (fm4tlp) Dynamic networks evolve continuously, yet link prediction models are typically trained on static snapshots. This project develops **transfer learning methodologies** for temporal link prediction, enabling models pre-trained on diverse source graphs to generalize to new target graphs with limited historical data. We demonstrate that cross-graph transfer provides substantial gains over conventional baselines, particularly in sparse or rapidly-evolving network settings. Published at *IJCNN 2025*. ### Inductive Link Prediction for Isolated Nodes Most link prediction models fail for newly-introduced or low-degree nodes due to over-reliance on topological neighborhoods. This research proposes inductive methods that remain accurate even for **isolated nodes in static and temporal graphs**, leveraging unsupervised pre-training to generate rich node representations independent of graph structure. The work demonstrates significant improvements in generalization for both newly added nodes and temporal edge prediction tasks. Presented at *NeurIPS 2023 Temporal Graph Learning Workshop*. ### Disentangling Node Attributes from Graph Topology This paper investigates a fundamental problem in GNN-based link prediction: models tend to memorize network configurations rather than learning generalizable node features. We study how to correctly **disentangle topological constraints** (path lengths, degree bias) from innate node attributes, and introduce novel formulations for unbiased inductive link prediction across unseen environments. The work provides theoretical and empirical insights into the nature of observational biases in graph learning. Published at *Complex Networks 2023*. ### SIENNA — Brain Tumor Diagnostics Platform SIENNA is a lightweight, generalizable machine learning platform for automated brain tumor diagnostics using MRI data. Built in collaboration with Northeastern University and clinical partners, it integrates CNN-based classification with efficient preprocessing to enable deployment in resource-constrained clinical environments. SIENNA achieves high diagnostic accuracy across diverse tumor types, contributing toward AI-assisted neurosurgical diagnostics. Preprint on *medRxiv* (2024). ### MultiViz — Gephi Plugin for Multilayer Networks MultiViz is a specialized Gephi plugin enabling scalable visualization and analysis of **multilayer networks** — complex systems where nodes interact across multiple dimensions or contexts. The tool lets researchers visualize interconnected network layers, compute multilayer centrality metrics, and derive actionable insights without writing custom rendering code. Particularly useful for biological networks, social networks, and infrastructural systems. --- See my [GitHub profile](https://github.com/ChatterjeeAyan) and [Google Scholar](https://scholar.google.com/citations?user=jQWO9kgAAAAJ&hl=en) for the full list of repositories and scientific contributions.
